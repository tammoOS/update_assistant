# Update Assistant for tammoOS

This tool allows you to update tammoOS to the latest version

1. Download the update assistant: ```bash
git clone https://github.com/tammoOS/update_assistant
```
3. Navigate to the script: ```bash
cd update_assistant
```
4. Make the script executable: ```bash
chmod +x update_assistant.sh
```
5. Run the script: ```bash
./update_assistant.sh
```
